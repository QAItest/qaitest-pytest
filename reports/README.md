# Reports examples

This folder can store generated test reports and example report formats.

Included example:

- [cucumber-report-example.json](C:/Users/g.prospa/Documents/Team_Software/QA/5-PROJ/qaitest-pytest/reports/cucumber-report-example.json)

Notes:

- The structure is based on a real Cucumber JSON output produced by a BDD test run.
- The content has been anonymized and generalized for open-source reuse.
- The example includes both a fully passing scenario and a failing scenario to show common `result.status` values.
